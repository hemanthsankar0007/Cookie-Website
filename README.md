# Sweet Delights - Cookie Website 🍪

A beautiful, responsive cookie and sweets e-commerce website built with HTML, CSS, and JavaScript.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Shopping Cart**: Add items to cart, view totals, and manage your selections
- **Product Catalog**: Browse through various categories of sweets:
  - Cakes 🎂
  - Cupcakes 🧁
  - Sweets 🍬
  - Doughnuts 🍩
- **Search Functionality**: Find your favorite treats quickly
- **Category Filtering**: Filter products by type
- **Professional UI**: Beautiful color scheme and typography

## 🚀 Live Demo

Visit the live website: [Sweet Delights](https://hemanthsankar0007.github.io/Cookie-Website/)

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with custom properties and responsive design
- **JavaScript**: Interactive shopping cart and dynamic functionality
- **Bootstrap**: Grid system and responsive utilities
- **Font Awesome**: Beautiful icons
- **Google Fonts**: Custom typography (Poppins & Nunito Sans)

## 🚀 Getting Started

### Option 1: Visit the Live Site
Simply visit [https://hemanthsankar0007.github.io/Cookie-Website/](https://hemanthsankar0007.github.io/Cookie-Website/)

### Option 2: Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/hemanthsankar0007/Cookie-Website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Cookie-Website
   ```

3. Open `index.html` in your browser or start a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

4. Open your browser and go to `http://localhost:8000`

## 🛒 How to Use the Shopping Cart

1. **Browse Products**: Scroll down to see our delicious collection
2. **Add to Cart**: Click the shopping cart icon on any product
3. **View Cart**: Click the cart icon in the navigation to see your items
4. **Manage Cart**: Remove items or clear the entire cart
5. **Checkout**: Ready to purchase? Click the checkout button!

## 🎨 Customization

The website uses CSS custom properties for easy theme customization:

```css
:root {
  --primary-bg: #FFF8F0;     /* Creamy background */
  --secondary-bg: #6B4F4F;   /* Dark Brown */
  --accent-color: #D8A7B1;   /* Soft Rose/Pink */
  --text-color: #484848;     /* Dark Grey */
}
```
